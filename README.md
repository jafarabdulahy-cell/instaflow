# InstaFlow / Shanisgram v25

نسخه کامل پروژه برای تست Railway/Kiro.

## اجرا

```bash
npm install
npx prisma generate
npm run dev
```

اگر دیتابیس تازه است:

```bash
npx prisma db push
```
